## Dependency notes

- Plan 001 is internally gated: CLI characterization tests must land before
  the parser switch; the parser and cancellation work must pass before help,
  completion, version, and release artifacts are finalized.
- The current `cmd/`, `internal/`, and `docs/plans/` layout is uncommitted
  relative to `e8a7b47`. Capture that restructuring in a stable baseline before
  implementing the plan, or execute only with explicit operator confirmation
  that the dirty tree is the intended baseline.
- Plan 002 owns retry classification, backoff, cancellation, and request
  timeout configuration. Plans 003–005 must consume that policy rather than
  adding provider-local retry loops.
- Plans 003 and 004 may proceed in parallel after Plan 002. Plan 003 must land
  before Plan 005 because release creation and asset upload reuse its rule:
  never blindly retry a mutation; reconcile remote state first.
- Plan 005 is the v0.6.0 feature boundary. It removes the need to finish a Gew
  release with `gh release` or direct Gitea API calls.

## Findings considered and rejected

- **Ship as v0.4.2**: rejected. Successful command-specific help, a new `-v`
  alias, flexible flag placement, cancellation propagation, and completion are
  user-visible CLI changes. `v0.5.0` communicates the scope better for this
  pre-1.0 project.
- **Add `github.com/urfave/cli-docs/v3` to the main module**: rejected. Its
  current stable module requires Go 1.24.4, while `gew` promises Go 1.22.
- **Let urfave types enter workspace or forge packages**: rejected. The
  dependency belongs only at the CLI boundary.
- **Preserve the current non-zero exit for `<command> --help`**: rejected as an
  accidental limitation of `flag.FlagSet`; v0.5.0 deliberately makes help a
  successful operation.
- **Enable GitLab or Bitbucket push during this release**: rejected. Provider
  safety gates are unrelated to the CLI framework migration and remain in
  force.
- **Re-plan the CLI test-isolation bug**: rejected because it is already fixed
  in `internal/cli/command_test.go:22-36,137-159`. Keep the regression helper;
  do not duplicate the production work.
- **Automatically retry POST/PATCH/PUT/DELETE**: rejected. A timed-out mutation
  may already have succeeded; replay can duplicate commits, tags, or assets.
  Plans 003 and 005 reconcile immutable remote identity before another write.
- **Silently split one local commit into several remote commits**: rejected.
  The README promises one atomic remote commit per queued local commit. Plan
  003 adds streaming, diagnosis, and a safe uncommit/re-stage escape hatch.
- **Remove native archives and always fetch every blob**: rejected. Exact-
  revision archives remain the fast path; Plan 004 adds a bounded fallback.
