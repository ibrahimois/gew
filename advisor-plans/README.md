## Findings considered and rejected

- **Ship as v0.4.2**: rejected. Successful command-specific help, a new `-v`
  alias, flexible flag placement, cancellation propagation, and completion are
  user-visible CLI changes. `v0.5.0` communicates the scope better for this
  pre-1.0 project.
- **Add `github.com/urfave/cli-docs/v3` to the main module**: rejected. Its
  current stable module requires Go 1.24.4, while `gew` promises Go 1.22.
- **Let urfave types enter workspace or forge packages**: rejected. The
  dependency belongs only at the CLI boundary.
- **Preserve the current non-zero exit for `<command> --help`**: rejected as an
  accidental limitation of `flag.FlagSet`; v0.5.0 deliberately makes help a
  successful operation.
- **Enable GitLab or Bitbucket push during this release**: rejected. Provider
  safety gates are unrelated to the CLI framework migration and remain in
  force.
